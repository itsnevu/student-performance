==========================================================
      PANDUAN WORKFLOW AUDIT ML (REVISED - V2)
==========================================================
Proyek: Prediksi Kelulusan Mahasiswa (Enterprise Standard)

Berikut adalah struktur file yang sudah diperbaiki sesuai standar 
Senior ML Engineer untuk mencegah Data Leakage & Overfitting:

----------------------------------------------------------
FASE 1: LOAD DATASET
----------------------------------------------------------
-> src/data_loader.py
   - Membaca dataset CSV dari 'data/raw/'.
   - Penanganan otomatis pemisah (sep=;) & tipe data numeric.

----------------------------------------------------------
FASE 2: DATA PREPARATION (7 Teknik Dasar)
----------------------------------------------------------
-> src/preprocess.py
   1. Cleaning: Hapus duplikat.
   2. Imputation: Median/Modus.
   3. Transformation: Binary encoding awal.
   4. Outlier Handling: IQR Clipping.
   5. Normalization: (Pindah ke Pipeline/Engineering).
   6. Feature Scaling: (Pindah ke Pipeline/Engineering).
   7. Data Splitting: DILAKUKAN DI AWAL (Penting!)

----------------------------------------------------------
FASE 3: FEATURE ENGINEERING (5 Teknik Lanjutan)
----------------------------------------------------------
-> src/feature_engineering.py
   - Dilakukan setelah Splitting untuk mencegah kebocoran informasi.
   1. Feature Addition: 'Midterm_Avg'.
   2. Feature Extraction: 'Study_Efficiency', 'Fail_History'.
   3. Feature Reduction: Drop kolom redundant/leakage.
   4. Feature Selection: SelectKBest (F-Classif).
   5. Dimensionality Reduction: PCA (Principal Component Analysis).
   6. Scaling: Standardization (Z-Score) dilakukan di sini.

----------------------------------------------------------
FASE 4: MODELING (Tuning & Balancing)
----------------------------------------------------------
-> src/train.py
   - Imbalance Handling: SMOTE (Hanya dilakukan pada Data Train).
   - Hyperparameter Tuning: RandomizedSearchCV (Grid Search alternatif).
   - Model: LR, Random Forest, SVM, XGBoost.

----------------------------------------------------------
FASE 5: EVALUATION & INFERENCE
----------------------------------------------------------
-> src/evaluate.py (Dulu predict.py)
   - Matrix perbandingan (Acc, F1, AUC-ROC) & grafik.
-> src/predict.py
   - Digunakan khusus untuk inferensi data mahasiswa baru.

==========================================================
FILE EKSEKUSI
==========================================================
1. main.py: Menjalankan audit total ke semua dataset.
2. notebooks/01-eda.ipynb: Eksplorasi & Visualisasi awal.
3. notebooks/02-full-audit-pipeline.ipynb: Demo pipeline lengkap.
