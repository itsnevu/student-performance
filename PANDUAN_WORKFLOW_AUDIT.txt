==========================================================
      PANDUAN WORKFLOW AUDIT MACHINE LEARNING
==========================================================
Proyek: Prediksi Kelulusan Mahasiswa (Professional Audit)

Berikut adalah penjelasan fungsi setiap file berdasarkan urutan 
Workflow 5 Fase yang Anda minta:

----------------------------------------------------------
FASE 1: LOAD DATASET
----------------------------------------------------------
-> src/data_loader.py
   Fungsi: Membaca dataset (.csv) dari folder 'data/raw/'. 
   Keunggulan: Otomatis mendeteksi pemisah (;) dan membersihkan 
   format angka yang terbungkus tanda kutip agar tidak error.

----------------------------------------------------------
FASE 2: DATA PREPARATION (7 Teknik)
----------------------------------------------------------
-> src/preprocess.py (Fungsi: audit_preparation)
   Berisi implementasi 7 langkah persiapan:
   1. Cleaning: Hapus data duplikat.
   2. Imputation: Isi nilai null (Median/Modus).
   3. Transformation: Encoding kategori ke angka.
   4. Outlier Handling: Teknik IQR Clipping untuk data ekstrem.
   5. Normalization/Scaling: Standarisasi nilai agar seragam.
   6. Imbalance Handling: Resampling agar kelas target seimbang.
   7. Data Splitting: Membagi data Train & Test (80:20).

----------------------------------------------------------
FASE 3: FEATURE ENGINEERING
----------------------------------------------------------
-> src/preprocess.py
   Berisi 3 teknik audit:
   1. Feature Addition: Membuat kolom 'Total_Score'.
   2. Feature Extraction: Membuat kolom 'Study_Efficiency'.
   3. Feature Reduction: Menghapus kolom asli yang sudah diolah 
      dan fitur tidak relevan untuk menjaga akurasi.

----------------------------------------------------------
FASE 4: MODELING (10 Model Pembanding)
----------------------------------------------------------
-> src/train.py
   Melatih 10 algoritma sekaligus untuk mencari yang terbaik:
   (LR, DT, RF, Naive Bayes, KNN, SVM, XGBoost, GradBoost, 
   AdaBoost, dan ANN).
   Model yang sudah dilatih disimpan otomatis di folder 'models/'.

----------------------------------------------------------
FASE 5: MODEL EVALUATION & BEST MODEL
----------------------------------------------------------
-> src/predict.py
   Menghitung metrik profesional (Accuracy, F1-Score, Precision, 
   Recall, AUC-ROC) dan menghasilkan grafik perbandingan model.
   Hasil audit visual disimpan di folder 'outputs/'.

==========================================================
FILE EKSEKUSI (OTOMASI & VISUALISASI)
==========================================================
1. main.py
   File utama untuk menjalankan seluruh workflow 1-5 secara 
   otomatis untuk semua dataset di folder 'raw'.

2. notebooks/02-full-audit-pipeline.ipynb
   Versi visual dari workflow 1-5. Gunakan ini untuk membuat 
   laporan atau presentasi hasil audit Anda.

3. src/logger.py & src/exception.py
   Mesin pendukung untuk mencatat aktivitas (logs) dan 
   menangani error secara profesional.
==========================================================
