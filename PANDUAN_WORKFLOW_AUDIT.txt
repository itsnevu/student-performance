FASE 1: DATA LOADING & EDA DASHBOARD
----------------------------------------------------------
-> src/data_loader.py
   - Proteksi FileNotFoundError.
   - Auto-detect Separator (CSV/Semicolon).
   - Laporan Otomatis: Shape, Duplikat, Missing Values.
   - Analisa Distribusi Kelas & Imbalance Ratio.

FASE 2: DATA PREPARATION (7 TEKNIK)
----------------------------------------------------------
-> src/preprocess.py
   1. Cleaning: Hapus duplikat.
   2. Imputation: Median (Numerik) & Modus (Kategorikal).
   3. Transformation: Individual LabelEncoder per kolom.
   4. Outlier Handling: Dynamic IQR Clipping (Exclude Target).
   5. Data Splitting: 80:20 Stratified Split (dengan guard).
   6. Normalization: (Logika di Fase 3).
   7. Imbalance Handling: (Logika di Fase 4).

FASE 3: ADVANCED FEATURE ENGINEERING (5 TEKNIK)
----------------------------------------------------------
-> src/feature_engineering.py
   1. Addition: Fitur Midterm_Avg.
   2. Extraction: Fitur Study_Efficiency.
   3. Reduction: Drop fitur redundan, PERTAHANKAN 'failures'.
   4. Normalization: OHE (Compatibility Guard) + Scaling.
   5. Selection & PCA: SelectKBest + Reduksi Dimensi via PCA.
   * OUTPUT: Menyimpan 'outputs/models/preprocessors.pkl' untuk inferensi.

FASE 4: MODEL COMPARISON & TUNING
----------------------------------------------------------
-> src/train.py
   - Handling Imbalance: SMOTE (Hanya pada data train).
   - 10 Model Audit: LR, DT, RF, NB, KNN, SVM, XGBoost, GB, AdaBoost, MLP.
   - Hyperparameter Tuning: RandomizedSearchCV (n_iter=10) + StratifiedKFold.
   - Save Models: Semua 10 model disimpan dalam format .pkl.

FASE 5: PROFESSIONAL EVALUATION & VIZ
----------------------------------------------------------
-> src/evaluate.py
   - Metrik Lengkap: Accuracy, F1-Score, Precision, Recall, AUC-ROC.
   - Robustness Check: Cross Validation Mean & Std (k=5 Stratified).
   - Dashboard Visual: Bar Chart (4 Metrik) + Confusion Matrix Best Model.
   - Save Report: Hasil disimpan di 'outputs/' (CSV & PNG).
